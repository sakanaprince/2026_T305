# TOWER DEFENSE（仮）

一人称視点（FPS）のアクション性と、戦略的なタワーディフェンスが融合した3Dアクションタワーディフェンスゲームです。プレイヤー自身が戦場を駆け回り、迫り来る敵から防衛対象（コア）を守り抜きます。

## 📑 ⚙️ ゲームシステム & ルール

### 🎯 勝敗条件
* **勝利条件:** 制限時間終了時に、防衛対象である「コア」のHPが残っていること。
* **敗北条件:** コアのHPが0になり、破壊されること。

### 🛡️ コアとプレイヤーの仕様
* **コア:** ステージの中心に位置する守るべき標的。敵が接触するとダメージを受けます。
* **プレイヤー（FPS視点）:** * レティクル（照準）に向かって弾を発射し、敵を撃破します。
    * 敵から攻撃を受けるとダメージを受け、**HPが0になるとコアの位置でリスポーン（再出撃）**します。
    * 敵は地上を歩いて侵攻しますが、プレイヤーは**ジャンプ**を使った立体的な立ち回りが可能です。

### 👾 敵（エネミー）のAIアルゴリズム
> 敵は基本的に最短ルートでコアを目指しますが、プレイヤーの位置によって標的を切り替えます。
1.  **通常時:** ステージの壁（障害物）を迂回しながら、コアへの最短ルートを移動。
2.  **ヘイト挙動:** プレイヤーが近くにいる場合、ターゲットをプレイヤーに変更して接近。
3.  **消滅条件:** 敵が「コア」または「プレイヤー」に接触すると、自身の攻撃力分のダメージを与えて消滅します。

---

## 💡 コアゲームプレイ（戦略とアクションの融合）

本作の最大の特徴は、**「壁（遮蔽物）を利用したリスク＆リターンの駆け引き」**です。

* **安全重視プレイ:** ステージ上の壁に身を隠し、敵の攻撃を受けにくい安全圏から狙撃する。
* **リスク提示プレイ:** あえて敵の進行ルート（通路）に飛び出し、危険を冒しながらも近距離で確実に高ダメージを狙う。

## ⌨️ 操作方法（Controls）

プレイヤーは以下のキーボード＆マウス操作でキャラクターをコントロールします。

* **`W` `A` `S` `D`** : 移動
* **`Shift`** : ダッシュ
* **`Space`** : ジャンプ
* **`マウス操作`** : カメラ視点移動
* **`左クリック`** : 攻撃（射撃）
* **`右クリック`** : 照準を合わせる（エイム）
